# Feast or Fiend — 更多 Boss 与小怪设计

**设计方向：** 食物本体 + 独特机制 + 社交关系 + 可喂食材变异 + 黑暗料理反噬。每个 Boss 标注外形、机制、喂食变异、社交关系、掉落。

> 工作草案：以下为内容设计提案，不代表已实现或已通过 G1/G2 范围审批。

## 一、小怪（野外食材来源）

小怪是“种子/基础食材”的产出源，设计上要一眼看出它掉什么，且行为有记忆点。

### 1. 暴躁西兰花（Angry Broccoli）

**外形：** 一棵会走路的小树，头顶花球像爆炸头，跑起来一颠一颠。

**机制：** 不主动攻击，但被靠近就喷射绿色小花球（小范围散射），花球落地变成小西兰花苗（可踩掉）。

**掉落：** 西兰花种子、西兰花。

**台词：** “我不是树！我是菜！……好吧我也是树。”

### 2. 洋葱骑士（Onion Knight）

**外形：** 套着洋葱皮当盔甲的小怪，手持牙签当长矛。

**机制：** 攻击时释放催泪气体（玩家屏幕轻微模糊 + 移速下降），自己也会被熏到流泪（攻击间隔变长）。

**掉落：** 洋葱种子、洋葱。

**台词：** “（流泪）我没哭！是盔甲的问题！”

### 3. 辣椒小贼（Chili Rascal）

**外形：** 细长红辣椒，跑得极快，背个小布袋。

**机制：** 偷食材——靠近玩家菜园会偷一颗作物就跑，打死后掉落偷走的东西 + 辣椒。

**掉落：** 辣椒种子、辣椒、被偷的作物。

**台词：** “嘿嘿嘿——（被追上）啊！辣的是我啊！”

### 4. 蘑菇间谍（Mushroom Spy）

**外形：** 一朵戴墨镜的蘑菇，走路无声。

**机制：** 伪装成普通蘑菇（地里随机出现假蘑菇），玩家靠近才现形，释放孢子云雾（短暂致盲）。

**掉落：** 蘑菇种子、蘑菇。

**台词：** “（现形）被发现了。……我其实只是想晒太阳。”

### 5. 玉米炮兵（Corn Artillery）

**外形：** 一根玉米，玉米粒像炮弹仓，叶子当炮架。

**机制：** 远程抛射玉米粒（抛物线弹道，落地爆炸小范围），近身则用玉米棒敲。

**掉落：** 玉米种子、玉米。

**台词：** “装填！……（咔）……卡壳了。等一下。”

### 6. 豆腐幽灵（Tofu Ghost）

**外形：** 半透明方块豆腐，飘着，边缘微微晃动。

**机制：** 物理免疫（普通攻击穿透），必须用锅铲拍打（近战特殊动作）或热水（烹饪系统道具）才能伤害。

**掉落：** 大豆种子、豆腐。

**台词：** “我……没有形状……（被拍）啊！我有形状了！”

### 7. 酸菜史莱姆（Pickle Slime）

**外形：** 一坨酸菜色的果冻状生物，弹跳移动。

**机制：** 死亡时爆裂溅射酸液（腐蚀地面，短暂形成酸池），酸池可用来腌制食材（隐藏机制：把食材丢进酸池获得“酸味”属性）。

**掉落：** 白菜种子、酸菜。

**台词：** “（弹跳）酸——！（爆）更酸了——！”

### 8. 面包虫群（Breadcrumb Swarm）

**外形：** 一群小面包屑组成的虫群，集体移动。

**机制：** 分裂——打死一只分裂成两只小的，必须一次性范围击杀或用油（烹饪道具）粘住它们。

**掉落：** 面粉、酵母。

**台词：** “（沙沙声）我们是……面包的……前身……”

## 二、Boss 设计

### 1. 汉堡王·双面堡（Double-Face Burger）

**外形：** 一个巨大的双层汉堡，上层是“笑脸”，下层是“怒脸”，两个脸会轮流主导。

**机制：** 双阶段切换——笑脸阶段温和（扔生菜叶，伤害低），怒脸阶段狂暴（肉饼冲撞 + 芝士喷射）。玩家需在笑脸阶段喂食材（此时它接受），怒脸阶段只能躲。

**喂食变异：**

- 喂培根 → **“培根双层堡”**，攻击附带油脂滑地（地面变滑）。
- 喂菠萝 → **“夏威夷堡”**（它自己很抗拒），攻击变成菠萝弹跳球。
- 喂错（如喂冰淇淋）→ **黑暗料理·融化堡**，狂化后满地流芝士，极难走位。

**社交关系：** 遇到薯条怪时，两者合体成“套餐”——汉堡骑在薯条上，获得移动速度 + 远程薯条射击组合技。

**掉落：** 汉堡菜谱 / 变异菜谱 / 黑暗料理。

**台词：** “（笑脸）欢迎光临～（怒脸）点单快点！”

### 2. 披萨教皇（Pizza Pontiff）

**外形：** 一张巨大的披萨，边缘翘起像教皇冠冕，芝士拉丝像权杖。

**机制：** 旋转切割——整张披萨旋转，边缘像锯片（碰到掉血），中心是安全区。旋转时甩出配料（橄榄、蘑菇、香肠）作为弹幕。打掉一定血量后切成六块，每块独立攻击。

**喂食变异：**

- 喂榴莲 → **“榴莲披萨教皇”**，释放气味领域（持续掉血 + 屏幕扭曲）。
- 喂巧克力 → **“甜品披萨”**，攻击变成甜腻黏着（减速 + 无法跳跃）。
- 喂错（如喂生鱼）→ **黑暗料理·海洋披萨**，狂化后召唤鱼群弹幕。

**社交关系：** 与意大利面怪是世仇（“你太散！”“你太圆！”），同场优先互殴，玩家可坐收渔利。

**掉落：** 披萨菜谱 / 变异菜谱 / 黑暗料理。

**台词：** “（旋转）以芝士之名——（甩配料）赐你饱腹！”

### 3. 火锅大仙（Hotpot Immortal）

**外形：** 一口悬浮的铜锅，锅底是沸腾红汤，周围飘着筷子当浮游炮。

**机制：** 温度条——锅底温度随时间上升，温度越高攻击越猛（沸腾溅射），玩家需投入冰块食材（如黄瓜、冬瓜）降温。筷子浮游炮会夹取场上食材（包括玩家丢的）强化自己。

**喂食变异：**

- 喂毛肚 → **“毛肚火锅仙”**，攻击附带七上八下（快速连续突刺）。
- 喂冰淇淋 → **“冰火火锅仙”**（它自己很困惑），攻击变成冰火两重天（交替冰冻/灼烧）。
- 喂错（如喂面包）→ **黑暗料理·糊底锅**，狂化后锅底焦糊（全场持续掉血 + 视野变暗）。

**社交关系：** 遇到冰淇淋怪时，两者互相克制（火锅想煮冰淇淋，冰淇淋想冻火锅），同时攻击玩家和对方（混乱三方混战）。

**掉落：** 火锅菜谱 / 变异菜谱 / 黑暗料理。

**台词：** “（沸腾）咕嘟咕嘟……你也想下来涮一涮？”

### 4. 寿司将军·三贯（Sushi General San-Kan）

**外形：** 三个寿司叠成武将铠甲造型（金枪鱼当胸甲、玉子烧当头盔、虾当佩刀），比之前的寿司怪高一级。

**机制：** 三段变身——每打掉 1/3 血，脱下一层寿司（金枪鱼→玉子烧→虾），每层有独立攻击模式：

- 金枪鱼层：鱼刀连斩（近战三连）。
- 玉子烧层：蛋液喷射（扇形弹幕）。
- 虾层：弹跳突刺（高速冲刺）。

**喂食变异：**

- 喂芥末 → **“芥末将军”**，所有攻击附带辣味灼烧（持续掉血 + 屏幕泛红）。
- 喂鳗鱼 → **“鳗鱼将军”**，攻击变成蒲烧缠绕（追踪弹 + 束缚）。
- 喂错（如喂牛奶）→ **黑暗料理·散架寿司**，狂化后三贯同时攻击（三层一起上，极难）。

**社交关系：** 与茶先生有师徒关系（“茶老师教我沉稳”），同场时茶先生会给寿司将军加 buff（“静心茶”：攻击更精准），玩家需先解决茶先生。

**掉落：** 寿司菜谱 / 变异菜谱 / 黑暗料理。

**台词：** “（拔鱼刀）三贯流·奥义——（斩）鲜度即是正义！”

### 5. 拉面龙（Ramen Dragon）

**外形：** 一条面条组成的长龙，汤底是龙头，叉烧是鳞片，溏心蛋是眼睛。

**机制：** 面条缠绕——龙身面条可伸长缠绕玩家（束缚 + 拖拽），玩家需切断面条（攻击特定节点）。龙会吸汤（地面出现汤池，踩进去减速），吸满后喷汤（大范围扇形）。

**喂食变异：**

- 喂辣椒 → **“地狱拉面龙”**，喷汤变成火焰汤（灼烧地面）。
- 喂玉米 → **“味噌玉米龙”**，攻击附带玉米粒弹幕（散射）。
- 喂错（如喂巧克力）→ **黑暗料理·甜汤龙**，狂化后汤池变黏（无法移动）+ 面条无限伸长。

**社交关系：** 与饺子怪是邻居（“老死不相往来但住对门”），同场时互相嫌弃但会合力（“先解决这个厨子再吵”）——罕见的 Boss 合作。

**掉落：** 拉面菜谱 / 变异菜谱 / 黑暗料理。

**台词：** “（龙吟）吸溜——！（面条甩出）我的面，比命长！”

### 6. 月饼嫦娥（Mooncake Chang'e）

**外形：** 一轮满月形状的月饼，表面印着嫦娥奔月图案，周围飘着玉兔小怪（辅助）。

**机制：** 月相变化——Boss 血量对应月相（满月→半月→新月），满月时防御极高（饼皮硬），新月时防御极低但攻击极快。玉兔会偷食材并喂给 Boss（玩家需拦截）。

**喂食变异：**

- 喂蛋黄 → **“双黄月饼嫦娥”**，召唤双玉兔（更多偷食材的）。
- 喂冰淇淋 → **“冰皮月饼嫦娥”**，攻击变成冰冻弹幕（减速）。
- 喂错（如喂辣椒）→ **黑暗料理·辣月饼**，狂化后玉兔暴走（变成攻击型），全场混乱。

**社交关系：** 与茶先生有思乡之情（“茶先生，你让我想起家乡的桂花茶”），同场时茶先生会给月饼加护盾（“思乡茶”：减伤），但月饼会停止攻击（陷入回忆），玩家可趁机输出。

**掉落：** 月饼菜谱 / 变异菜谱 / 黑暗料理。

**台词：** “（月相变化）月圆……月缺……你尝过乡愁的味道吗？”

### 7. 布丁国王（Pudding King）

**外形：** 一个巨大的焦糖布丁，戴着焦糖王冠，走路 Q 弹晃动，底部焦糖会滴落。

**机制：** 弹性物理——布丁身体极软（攻击会陷进去但反弹），玩家攻击会被弹开。需从上方砸（跳跃攻击）或用勺子道具（特殊武器）才能有效伤害。焦糖滴落形成黏着地面。

**喂食变异：**

- 喂芒果 → **“芒果布丁王”**，攻击附带芒果块弹射（弹跳弹幕）。
- 喂焦糖 → **“double 焦糖布丁王”**，焦糖地面扩大（更多黏着区）。
- 喂错（如喂酱油）→ **黑暗料理·咸布丁王**，狂化后 Q 弹变硬（防御翻倍）+ 焦糖变黑（灼烧）。

**社交关系：** 与蛋糕夫人是表亲（“我们都是甜品界的贵族”），同场时互相增益（蛋糕夫人加攻、布丁国王加防），形成甜品双王，极难打。

**掉落：** 布丁菜谱 / 变异菜谱 / 黑暗料理。

**台词：** “（晃动）朕……很软。但朕……很尊贵。”

### 8. 烤鸭侠（Roast Duck Hero）

**外形：** 一只油光发亮的烤鸭，披着荷叶饼披风，手持葱段双刀，戴着甜面酱面具。

**机制：** 飞行 + 俯冲——烤鸭会飞起（近战打不到），俯冲时用葱刀斩击。地面有甜面酱池（减速），空中会撒荷叶饼（落地形成障碍）。需用远程或击落（打中翅膀使其坠地）。

**喂食变异：**

- 喂蜂蜜 → **“蜜汁烤鸭侠”**，俯冲附带火焰尾迹（灼烧路径）。
- 喂黄瓜 → **“清爽烤鸭侠”**，攻击变成黄瓜条弹幕（散射），但防御降低。
- 喂错（如喂酸奶）→ **黑暗料理·酸败烤鸭**，狂化后飞行失控（随机乱撞）+ 甜面酱变酸（腐蚀）。

**社交关系：** 与汉堡王是竞争对手（“快餐界一哥之争”），同场时互相嘲讽（“你个夹肉的！”“你个卷饼的！”），攻击力互相提升（斗气），但防御降低（分心）。

**掉落：** 烤鸭菜谱 / 变异菜谱 / 黑暗料理。

**台词：** “（展翅）葱刀出鞘——（俯冲）片鸭式·斩！”

### 9. 汤圆忍者（Tangyuan Ninja）

**外形：** 一颗白色汤圆，围着黑芝麻围巾（当忍者面罩），手持牙签苦无，走路无声滚动。

**机制：** 隐身 + 分身——汤圆会滚进汤里隐身（地面有汤池），从随机方向突袭。血量低时分裂成多个小汤圆（分身），真身芝麻馅会漏（地上有黑点线索）。

**喂食变异：**

- 喂抹茶 → **“抹茶汤圆忍者”**，隐身时留下绿色残影（更容易追踪），但攻击附带茶香迷惑（屏幕泛绿）。
- 喂花生 → **“花生汤圆忍者”**，分身更多（花生碎分身），但真身更明显（花生颗粒大）。
- 喂错（如喂咖啡）→ **黑暗料理·咖啡汤圆**，狂化后极度亢奋（攻速翻倍）+ 隐身无规律（极难预判）。

**社交关系：** 与寿司将军是同门（“我们都是日式料理的忍者”），同场时互相配合（寿司斩击 + 汤圆偷袭），形成日料双忍，需同时应对。

**掉落：** 汤圆菜谱 / 变异菜谱 / 黑暗料理。

**台词：** “（滚入汤中）……（从背后出现）汤圆流·影缝。”

### 10. 烤肉串帮（BBQ Skewer Gang）

**外形：** 三串烤肉组成的小帮派——羊肉串老大（粗壮）、鸡翅串老二（灵活）、韭菜串小弟（细长），串在竹签上，走路一跳一跳。

**机制：** 三体协同——三串共享血量，但各自独立攻击：羊肉串冲撞、鸡翅串空中回旋、韭菜串远程抽打。打掉任意两串，剩下的狂暴（攻速翻倍）。需均衡输出或快速秒杀。

**喂食变异：**

- 喂孜然 → **“孜然烤肉帮”**，所有攻击附带香气迷惑（玩家攻击方向随机偏移）。
- 喂辣椒 → **“麻辣烤肉帮”**，攻击附带辣味灼烧（持续掉血）。
- 喂错（如喂果酱）→ **黑暗料理·甜腻烤肉帮**，狂化后互相黏连（变成一坨大肉串，范围攻击）。

**社交关系：** 与披萨教皇有街头恩怨（“你抢我们夜市生意！”），同场时优先互殴（三串打一张饼），玩家可捡漏。

**掉落：** 烤肉菜谱 / 变异菜谱 / 黑暗料理。

**台词：** “（三串齐声）夜市三兄弟——（冲撞/回旋/抽打）——烤的就是你！”

## 四、黑暗料理连锁反应（喂错后的特殊互动）

黑暗料理不仅是“削弱道具”，还可以设计连锁玩法：

- **喂给有社交关系的 Boss：** 黑暗料理效果翻倍（如给茶先生喂黑暗料理，蛋糕夫人会愤怒狂化——“你竟敢喂他吃这个！”）。
- **喂给世仇 Boss：** 被喂的 Boss 暂时与玩家结盟打仇人（“敌人的敌人是朋友”）。
- **黑暗料理 + 黑暗料理：** 两个被喂黑暗料理的 Boss 同场，会互相吞噬（融合成超级黑暗料理怪，掉落双份特殊道具）。
